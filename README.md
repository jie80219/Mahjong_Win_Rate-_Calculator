# 麻將勝率計算器

四人麻將對局紀錄統計工具，記錄牌局結果並即時計算各項勝率指標。

## 功能

- **玩家管理**：新增、改名、隱藏玩家（隱藏不影響歷史統計）
- **建立牌桌**：選 4 人、排座位（東南西北）、選莊家、設定底／台錢與莊家台算法
- **牌桌式記錄**：點胡牌的人 → 點放槍的人或「自摸」→ 選台數，支援流局
- **莊家系統**：自動輪莊、連莊、圈風（東風東～北風北），打完一將提示結算；修改舊牌局會自動重算後續莊家與金額
- **金額計算**：底＋台×台錢，莊家台（1 + 2×連莊）可選「標準」或「僅閒家自摸」；全部紀錄模式可跨牌桌加總
- **結算**：最少轉帳次數、一鍵複製結算文字、產生戰報圖卡分享到群組
- **分享牌桌**：產生連結或 QR code，牌友開啟即可合併到自己的裝置（不經伺服器）
- **統計儀表板**：自摸率、胡牌率、放槍率、被摸率、大牌率、放大槍率、勝率、流局率
- **五種檢視模式**：長條圖、折線圖（含金額走勢）、清單、卡片、趣味
- **趣味統計**：稱號（自摸王、連莊王、放槍之王…）、相剋關係表、台數分布、個人風格、連胡／乾旱紀錄
- **篩選功能**：依牌桌、玩家、日期範圍篩選統計
- **歷史紀錄**：查看、編輯、刪除牌局紀錄
- **PWA**：可加到主畫面、離線使用；打牌時螢幕保持常亮
- **資料備份**：JSON 匯出 / 匯入（含玩家名單）、HTML 報表

## 統計定義

| 指標 | 公式 | 說明 |
|------|------|------|
| 自摸率 | S / K × 100% | 自己以自摸贏牌 |
| 胡牌率 | (S + R) / K × 100% | 自摸與榮胡合計 |
| 放槍率 | L / K × 100% | 打出的牌讓別人榮胡 |
| 被摸率 | M / K × 100% | 其他玩家自摸時被計入 |
| 大牌率 | C / K × 100% | 贏得五台以上的牌局 |
| 放大槍率 | B / K × 100% | 放槍給五台以上的贏家 |

- K = 有效局數（排除流局）
- 流局次數獨立顯示，不計入百分比
- 五台以上自摸不增加其他三人的放大槍次數

## 技術

- React + TypeScript + Vite
- Recharts（圖表）
- Dexie（IndexedDB 封裝）
- 純前端，資料存在瀏覽器本機

## 開發

```bash
npm install
npm run dev
```
