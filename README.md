# 麻將勝率計算器

四人麻將對局紀錄統計工具，記錄牌局結果並即時計算各項勝率指標。

## 功能

- **建立牌桌**：從 12 位玩家中選取 4 人開始對局
- **記錄牌局**：支援自摸、榮胡、流局三種結果，搭配台數紀錄
- **統計儀表板**：自摸率、胡牌率、放槍率、被摸率、爆擊率、被爆率
- **四種檢視模式**：長條圖、折線圖、清單、卡片
- **篩選功能**：依牌桌、玩家、日期範圍篩選統計
- **歷史紀錄**：查看、編輯、刪除牌局紀錄
- **資料備份**：JSON 匯出 / 匯入

## 統計定義

| 指標 | 公式 | 說明 |
|------|------|------|
| 自摸率 | S / K × 100% | 自己以自摸贏牌 |
| 胡牌率 | (S + R) / K × 100% | 自摸與榮胡合計 |
| 放槍率 | L / K × 100% | 打出的牌讓別人榮胡 |
| 被摸率 | M / K × 100% | 其他玩家自摸時被計入 |
| 爆擊率 | C / K × 100% | 贏得五台以上的牌局 |
| 被爆率 | B / K × 100% | 放槍給五台以上的贏家 |

- K = 有效局數（排除流局）
- 流局次數獨立顯示，不計入百分比
- 五台以上自摸不增加其他三人的被爆次數

## 技術

- React + TypeScript + Vite
- Recharts（圖表）
- Dexie（IndexedDB 封裝）
- 純前端，資料存在瀏覽器本機

## 開發

```bash
npm install
npm run dev
```
